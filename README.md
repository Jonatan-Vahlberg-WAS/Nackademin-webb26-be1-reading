# Library API

A simple library management system built with Node.js and Express@5. This repo serves as a code reading exercise.

## Starting the server
1. Copy the .env.example file to .env and fill in the values.
2. Install the dependencies
3. Start the server
```bash
npm install
npm run dev # starts the server on port 3000 with wathc
```

## Code reading
This repository will be split into lesson based branches. The code will be commented to the best of my ability to help you understand the code.


### Code explenations
- src folder - contains all our code.
- .env - contains all our environment variables.
- `src/config/env.js` - contains the code to load the environment variables from the .env file.
- `src/index.js` - contains the code to start the server. When introduced.
- `package.json` - contains the node configuration for the project. Example being scripts and dependencies.

Other code will have inline comments to help you understand the code.
